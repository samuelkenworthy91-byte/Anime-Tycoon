# Anime Runner

An anime-studio tycoon game. React + Vite web app, packaged for Android with Capacitor.

The source of truth is **`game_source/`**. Everything else in this repo is
supporting material.

---

## Building the APK

> **Important:** you cannot build the APK from the `android/` folder alone.
> `android/app/src/main/assets/public/` holds the web build and is generated by
> `cap sync` — it is intentionally not committed. Running `./gradlew assembleDebug`
> on a fresh clone produces an installable APK that opens to a **blank screen**,
> with no game art, no logo and no save data, because the web app was never
> copied in.

### Option A — GitHub Actions (recommended)

Every push runs `.github/workflows/apk.yml`, which does the full pipeline and
verifies the art actually made it into the package.

1. Go to the repo's **Actions** tab
2. Pick **Build Android APK** → the run for your branch (or click
   **Run workflow** to trigger one manually)
3. Download the **`anime-tycoon-debug-apk`** artifact from the run summary
4. Unzip it and install `app-debug.apk`

The workflow fails loudly if `dist/img` is empty or the logo is missing from the
build, so a broken APK can never be published silently.

### Option B — locally

Requires Node 20+, JDK 21 and the Android SDK.

```bash
cd game_source
npm ci
npm run apk:build
```

`apk:build` runs `vite build` → `cap sync android` → `gradlew assembleDebug`, in
that order. The APK lands at:

```
game_source/android/app/build/outputs/apk/debug/app-debug.apk
```

Useful individual steps:

| Command             | What it does                                        |
| ------------------- | --------------------------------------------------- |
| `npm run dev`       | Dev server with hot reload                           |
| `npm run build`     | Web build → `dist/` (`index.html` + `img/`)          |
| `npm run apk:sync`  | Build, then copy the web build into `android/`       |
| `npm run apk:build` | The above, then assemble the debug APK               |
| `npm run apk:open`  | Open the project in Android Studio                   |

### Checking an APK actually contains the art

```bash
unzip -l game_source/android/app/build/outputs/apk/debug/app-debug.apk \
  | grep -c "assets/public/img/"     # expect 60+
```

## Saving

The game autosaves to `localStorage` after every change while a career is in
progress, and **CONTINUE** appears on the title screen when a save exists.
Saves are retired when a career ends (bankruptcy or the end of the twelve
years) and when you start a new career. The Hall of Fame score table is stored
separately and is never cleared by starting a new run.

## Assets

All game art lives in `game_source/public/img/` and is copied verbatim into the
build. Android launcher icons in `game_source/android/app/src/main/res/mipmap-*`
are generated from `public/img/app-icon.png` and are committed.
