# Auction IP poster drop folder

Place user-created WebP files here using the stable names `poster_001.webp` through `poster_080.webp`. Slots 001–037 are currently assigned; slots 038–080 are reserved. Missing files automatically use the in-game labelled fallback card.

Run `npm run auction-ip:validate-posters` to report missing, oversized, or out-of-range poster assets.
