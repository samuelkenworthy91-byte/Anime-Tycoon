# Save Migration Notes

This expansion keeps the existing storage envelope and slot keys. `migrateRun()` adds neutral defaults for `ipMarket`, `strategicSpend`, `capitalProjects`, `staffContracts` and project `interventions`.

Legacy projects have no `licensedIpId`, so they remain original productions. Existing genres, arc knowledge, project history, franchises, cast discovery and rival state follow the existing migrations. Rights are never inferred from old franchises. IDs use stable `ip_NNN`, `auc_*` and definition IDs.

Focused migration tests confirm old genre unlocks and Hall of Fame history survive while new objects initialise.
