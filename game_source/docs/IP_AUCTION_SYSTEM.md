# IP Auction System

`src/engine/ip.ts` contains the canonical initial catalogue, contracts and pure auction transactions.

Auctions refresh every eight weeks after the first week-four notice. Early eligibility favours cult/emerging work; studio prestige progressively admits premium and legendary properties. Open, sealed, distressed and invite-only records share one stable schema so their UI and save migration remain compatible.

Rivals bid on weekly ticks. Their ceiling uses persistent reputation, tier and preferred-genre fit. Wins are stored in `rivalOwned` and the rights history. Player wins deduct cash at expiry, create a time-limited contract and never create ordinary cast employees.

Appraisal has three reveal levels. Archive tier currently supplies Legal/Data capability. Negotiations can improve sequel, merch, international and royalty terms, cost real cash, and can fail.

Licensed setup uses owned IP → property arc → format/budget/scope → direction sliders. Staff remain assigned on the normal project board; marketing remains a release decision. The setup has no normal cast screens.

At release the contract applies royalties, ownership revenue and existing-fan expectation effects. Strong adaptations may discover the property's studio-wide story blueprint. Locked blueprints become usable by original productions in the existing arc picker.
